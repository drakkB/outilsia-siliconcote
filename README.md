# SiliconCote

Native Rust application that collects AI hardware prices from your own computer: graphics cards, parts and complete machines, new, used and refurbished. It dates each reading, sets aside off-topic listings, composes a machine around the parts you own and answers your AI agents through MCP. No account, no AI API key.

- **Page and download:** https://outilsia.fr/telecharger-siliconcote
- **Public version:** 0.4.5 experimental preview (2 October 2026), Windows x64 and Linux x64. Free, MIT licence.

This repository holds release notes and checksums, without source code or binaries. Files are served by outilsia.fr; see [Releases](../../releases).
